# Tools Required for Machine Learning

This document lists the essential tools needed for learning and building Machine Learning projects.

---

# 1. Python

Python is the most popular programming language for Machine Learning because of its simplicity and rich ecosystem of libraries.

**Why Python?**

- Easy to learn
- Large community support
- Huge collection of ML and AI libraries
- Used in research and industry

---

# 2. Code Editor / IDE

A code editor is where you write and run your code.

### Recommended

- **Visual Studio Code (VS Code)** ⭐
- PyCharm

VS Code is lightweight, highly customizable, and widely used by developers.

---

# 3. Python Package & Environment Manager

Virtual environments keep project dependencies separate and avoid version conflicts.

### Recommended

- **uv** ⭐ (Modern & Fast)
- `venv` (Built into Python)

> **Note:** Anaconda/Conda is optional today. Most beginners and professionals can work efficiently using `uv` or `venv`.

---

# 4. Jupyter Notebook

Jupyter Notebook lets you write code, explanations, and visualizations in the same document.

It is commonly used for:

- Data Analysis
- Experimentation
- Learning ML concepts
- Creating reports

---

# 5. Git

Git is a Version Control System (VCS) used to track changes in your code.

It helps you:

- Save project history
- Collaborate with others
- Revert to previous versions

---

# 6. GitHub

GitHub is a cloud platform for hosting Git repositories.

It is used to:

- Store projects online
- Share code
- Build a portfolio
- Collaborate with teams

---

# 7. Google Colab

Google Colab is a cloud-based Jupyter Notebook service.

**Benefits:**

- No installation required
- Free GPU & TPU (limited)
- Easy sharing
- Runs directly in the browser

It is ideal when your local computer is not powerful enough for training models.

---

# 8. Terminal / Command Line

The terminal is used to:

- Install packages
- Create virtual environments
- Run Python scripts
- Execute Git commands

Learning basic terminal commands is highly recommended.
